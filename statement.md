# Project Statement – Movie Recommendation System

## 1. Problem Statement

With thousands of movies available on different platforms, users often find it difficult to decide what to watch. This project aims to develop a Java-based Movie Recommendation System that suggests movies similar to a movie selected by the user. The system uses movie genres, keywords, and overview to calculate similarity and provide relevant recommendations.

## 2. Scope of the Project

The project focuses on developing a simple content-based movie recommendation system using Java. It processes movie data from a CSV dataset, calculates similarity using cosine similarity, and displays the top 5 recommended movies. The system also uses the OMDb API to provide additional movie information such as posters, director, actors, year, and IMDb rating.

## 3. Target Users

- Movie enthusiasts looking for similar movies
- Students and beginners learning recommendation systems
- Users who want a simple movie discovery tool
- Developers interested in Java-based AI/ML projects

## 4. High-Level Features

- 🎬 Search and select movies from the dataset
- 🔍 Content-based movie recommendations
- 📊 Cosine similarity calculation
- ⭐ Top 5 similar movie suggestions
- 🖼️ Movie posters and details using OMDb API
- 💻 User-friendly Java Swing interface
- 📁 CSV-based movie dataset processing
